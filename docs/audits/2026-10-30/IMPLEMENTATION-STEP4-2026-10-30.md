## 반영한 기능

| 영역 | 변경 |
|---|---|
| 기록할 아기 | 성장·접종 화면 상단에서 아기를 직접 선택. 이름·생년월일·현재 월령 표시. 아기를 바꿔도 보고 있던 성장/접종 탭 유지 |
| 발달 관찰 | 항목을 관찰로 표시할 때 실제 관찰 날짜를 선택하고 저장. 저장된 날짜 확인·수정 제공. 관찰 취소는 확인 후 처리 |
| 날짜 검증 | 잘못된 달력 날짜, 미래 날짜, 출생 전 날짜 거부. 관찰·접종 저장소에서도 같은 검증 수행 |
| 아기별 저장 | 성장 수정·삭제, 관찰 저장·취소, 접종 저장·취소가 현재 아기의 기록만 처리. 다른 아기 ID나 바뀐 대상의 요청 거부. 기존 소유자 없는 기록은 고정된 legacyOwnerId 기준 유지 |
| 성장 기록 월령 | 저장·수정 시에도 측정 날짜로 만 개월을 다시 계산. 화면에 전달된 월령을 그대로 신뢰하지 않음. 앱 범위에 맞춰 12개월 상한 적용 |
| 입력 보존 | 측정 입력 중 뒤로 이동했다 돌아오면 아기별 임시 초안 복구. 새 기록/수정 중인 기록을 분리하고, 원본이 바뀐 기록에는 오래된 초안을 적용하지 않음 |
| 초안 정리 | 저장 또는 명시적 ‘버리고 닫기’에서 해당 초안 정리. 최대 20개 임시 입력만 유지. 세션 저장이 차단되면 실행 중 메모리에서 보존 |
| 성장 차트 | 축 글자 14px, 세로축 단위 표시. 실제 측정값은 점+선, 남아 기준은 실선, 여아 기준은 점선으로 범례 구분 |

전체 UI 방향과 기존 하단 메뉴는 유지했다. 발달 관찰은 기존 백과의 ‘발달 체크’에서 이용한다. 기존 의료·성장·예방접종 기준 데이터와 임상 문구는 수정하지 않았다.

### 실제 브라우저 흐름

- 기록 화면에서 A의 키 58.4cm와 B의 키 60.1cm를 전환해 확인. 성별 참고 기준도 해당 아기에 맞게 초기화.
- 접종 탭을 연 상태에서도 아기 선택과 탭 유지 확인.
- 가상 A의 관찰일을 2026-10-18로 저장한 후 2026-10-12로 수정. 관찰 수는 1/13 유지. 새로고침 후에도 날짜 유지.
- 관찰일에 2026-10-31(미래), 2026-08-28(출생 전)을 입력하면 가까운 오류 문구 표시.
- 관찰 취소 확인을 열고 ‘기록 유지’로 취소해 관찰 보존.
- 같은 항목을 가상 B로 열었을 때 관찰 수 0, A의 관찰 날짜가 나타나지 않음.
- 가상 B의 새 측정에 키 60.2cm와 메모를 입력하고 브라우저 뒤로 이동. 다시 열자 입력과 복구 안내가 표시됨. 저장 후 B 기록은 2건, A의 기존 58.4cm 기록은 유지.
- 저장 후 새 측정 시트를 다시 열었을 때 값과 메모가 비어 있고 복구 안내가 사라짐.
- B의 B형간염 1차 접종일을 저장한 뒤 수정. B의 접종 기록은 1건으로 유지되고 A의 기존 2건은 보존.
- 실제 360px에서 관찰 날짜 편집과 성장 차트에 가로 넘침 없음. 390px에서 아기 선택과 입력 복구 확인.

회귀 검사는 실제 TypeScript 저장소를 별도 메모리 상태에서 실행한다. 다른 아기 수정/삭제 방지, 관찰 날짜 수정 시 개수 유지, 날짜·대상 검증, 중복 접종 방지, legacy 기록 보존, 게스트 쓰기 거부, 초안 분리·복구·정리를 포함한다.

검증에는 가상 프로필과 로컬 QA 프록시를 사용했다. 프록시 쓰기 요청은 0건이며 운영 DB에 테스트 기록을 업로드하지 않았다. 현재 미리보기의 가상 B에는 이번 검증용 측정 1건과 접종 1건, 가상 A에는 관찰 1건이 추가돼 있다.

## STEP 5 전 추가 개선: 기록할 아기 선택 디자인

반영일: 2026-10-30. 기존 기본 드롭다운을 아바타·이름·월령·생일이 있는 카드와 하단 선택창으로 교체했다. 카드 전체를 누르거나 ‘변경’을 누르면 같은 선택창이 열린다.

- 각 아기를 큰 선택 행으로 표시하고 현재 아기는 브랜드 색 테두리·배경·체크로 구분한다. 사진이 없으면 아기 아이콘을 표시한다.
- 선택하면 해당 아기의 기록으로 전환하고 선택창을 닫는다. 성장/예방접종 탭은 유지한다. 아기가 한 명이면 정보 카드만 표시한다.
- 선택된 행으로 초기 포커스를 이동하고, Tab 포커스 순환·Escape 닫기·트리거로 포커스 복귀를 제공한다. 긴 목록은 선택창 안에서 스크롤한다.
- 휴대폰에서는 하단 시트, 넓은 화면에서는 최대 440px의 둥근 선택창을 사용한다. 안전 영역과 동작 줄이기 설정을 반영했다.

추가 검증: 컴포넌트 ESLint 오류/경고 0, TypeScript 검사 통과, 프로덕션 빌드 통과. 360px/390px에서 가로 넘침 없이 표시됐다. 브라우저에서 A→B 전환 시 최근 키 58.4→60.2cm로 갱신됐으며, 예방접종 탭에서 A로 돌아와도 탭과 기존 접종 2건이 유지됐다. Escape·닫기 버튼·선택 후 포커스 복귀를 확인했고 브라우저 콘솔 오류는 없었다. STEP 5 작업은 시작하지 않았다.

### 홈 탭에도 같은 선택창 적용

홈 상단의 기본 드롭다운도 같은 ‘변경’ 버튼과 하단 선택창으로 교체했다. 인사말·사진 변경·월령·생후 일수 표시는 유지하고, 카드 여백과 사진 크기를 기록 탭에 맞췄다. `src/components/baby/BabySelector.tsx`를 공통 컴포넌트로 추출해 두 화면이 같은 아기 목록·선택 표시·사진·키보드 동작을 사용한다. 기록 화면의 래퍼는 기존 제목·설명·배치를 유지한다.

360px/390px에서 가로 넘침 없이 확인했다. 홈에서 A→B 선택 시 이름, 최근 성장 기록(키 58.4→60.2cm), 미완료 접종 안내(4→5건)가 함께 갱신됐다. A로 복귀한 뒤 Tab 이동·Escape 닫기·트리거 포커스 복귀와 기록 탭의 선택창도 확인했다. 변경 파일 ESLint와 TypeScript 검사, 최종 소스의 Webpack 프로덕션 빌드(`npm run build -- --webpack`)를 통과했다. 테스트 프로필을 선택하기만 했으며 새 기록을 저장하지 않았다.

기본 Turbopack 재빌드에서는 `next/font/google queries have exactly one entry` 폰트 처리 오류가 발생했다. 폰트 설정과 빌드 설정은 변경하지 않았으며, 기본 빌드 재현 문제는 별도 확인이 필요하다.
