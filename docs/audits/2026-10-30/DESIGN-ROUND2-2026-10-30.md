## 유사 앱 비교와 적용 판단

2026-10-29~30에 공식 소개와 공개된 앱 화면을 확인했다. 설치한 앱의 최신 버전 전체를 직접 사용한 비교는 아니며, 공개 홍보 이미지 중에는 오래된 화면도 포함된다. 아래 적용 방향은 화면 관찰을 INFANTPEDIA에 맞게 해석한 디자인 판단이다.

경쟁 앱의 자산이나 화면을 복제하지 않았다. INFANTPEDIA의 백과·발달·접종 기능에 필요한 정보 위계와 일관된 색상 규칙으로 적용했다.

## 코드 확인

- `npm run lint`: 오류 0 / 경고 0. 마지막 소규모 월령·설정 수정도 해당 파일 ESLint 통과.
- `npm run check:ux`: 기록 소유권·날짜 계산 관련 기존 회귀 검사 13개 통과.
- `npm run build`: 23개 경로 생성, TypeScript 포함 통과.
- `git diff --check`: 공백 오류 없음. Windows 줄바꿈 안내만 발생.
- Next.js의 기존 middleware 파일명 사용 중단 예정 경고는 남아 있음.

## 브라우저 확인

- 새 월령 목록의 선택/접기, 선택 후 토글로 포커스 복귀.
- 토글에 포커스가 남아 있는 상태와 목록 안에서 Escape로 닫기.
- 0개월의 이전 버튼, 12개월의 다음 버튼 비활성화.
- 현재 아기 월령으로 복귀, 주제를 바꿔도 month URL 유지.
- 실제 innerWidth 360/390/430px에서 백과 상단 가로 넘침 없음.
- 360px의 선택된 12개월도 한 줄, 월령 버튼 48px 이상. 주제 버튼은 84px 높이.
- 홈·성장·접종·꿀팁·설정의 390px 화면과 다크 모드 확인.
- 게스트 상태에서도 6→7개월 이동과 정적 수면 가이드 열기 확인.
- 꿀팁에서 6개월 식단을 열고 요일을 바꾸면 선택/본문이 함께 갱신됨. 오늘 표시는 한국 날짜 기준.
- 검증한 QA 탭에서 브라우저 error 로그 없음.

브라우저 검증은 가상 프로필과 로컬 QA 프록시를 사용했다. 실제 휴대폰의 키보드·스크린리더·시스템 글꼴 확대 검증은 별도 과제다.

## 남은 작업

- 온라인 월령 콘텐츠의 Supabase 연결은 계속 실패한다. 월령 요약의 오류/재시도 상태와 정적 가이드는 동작하지만, 운영 데이터·로그인·클라우드 동기화의 정상 작동을 이번 QA로 확인한 것은 아니다.
- 정적 가이드 청크를 처음 불러올 때 깊은 읽기 위치의 복원은 별도 보완이 필요하다.
- 디자인 개선과 별도로 기존 감사에 적은 서버 권한/RLS, 공유 동기화, 콘텐츠 출처·의학 검수 과제는 남아 있다.
- 이번 결과는 로컬 코드와 미리보기다. GitHub 푸시·PR·배포는 수행하지 않았다.
