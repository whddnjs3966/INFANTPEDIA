## 검증 결과와 한계

- STEP 4 시점 회귀 검사: 기록 22개, 기존 UX 13개, 탐색 10개로 총 45개 통과.
- 마지막 홈 선택 UI 변경 파일: ESLint 오류/경고 0, TypeScript 검사 통과.
- 최종 소스: `npm run build -- --webpack` 프로덕션 빌드 통과.
- 기본 Turbopack 재빌드는 `next/font/google queries have exactly one entry` 폰트 처리 오류가 발생했다. 기본 빌드 문제는 별도 확인이 필요하며 폰트·빌드 설정은 변경하지 않았다.
- 360px·390px에서 홈/기록 선택창과 이름·버튼 배치, 가로 넘침, 아기 전환, 키보드 닫기 및 포커스 복귀 확인.
- 가상 A/B 전환 시 홈의 최근 키 58.4→60.2cm, 미완료 접종 안내 4→5건으로 갱신 확인. 기록 탭에서도 선택창 유지 확인.
- 테스트는 가상 프로필과 로컬 QA 프록시를 사용했다. 운영 DB에 테스트 기록을 업로드하지 않았다. 미리보기에 남은 가상 기록을 실제 사용자 기록으로 오해하지 않는다.
- 실제 iOS/Android, 스크린리더, 큰 글자, 부모 대상 사용성 검증과 의료 검수는 아직 완료하지 않았다.

## 남은 작업 — 진행 순서

### 1. STEP 5: 건강 정보·생활 자료

- [ ] 현재 구현과 진행표를 먼저 비교해 이미 반영된 UI를 다시 만들지 않기
- [ ] 꿀팁의 선택 월령·요일·시간표/식단 펼침 상태를 이동 후에도 유지
- [ ] 오늘 요일 초기 선택과 ‘다른 팁 보기’ 동작 확인·보완
- [ ] 월령에 맞는 팁과 공통 팁의 적용 범위를 명확히 표시

- [ ] 건강 FAQ 검색·주제·긴급 안내의 정보 위계 점검

- [ ] 가족 권한과 초대 유효성, 취소·만료·복사 피드백 검증
