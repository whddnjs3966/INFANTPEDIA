- 변경 전 6개월의 8개 화면/113개 패널, 변경 후 2·6·11개월의 24개 화면/322개 패널을 자동으로 펼쳐 검사했다. 여기서 패널 수는 월령별 반복 확인을 포함하며 서로 다른 글 322개를 의미하지 않는다. 새 하위 접힘과 참고 자료도 열었다.

## 그림과 공통 읽기 규칙

- **새 자체 SVG 8종:** 책·딸랑이·이유식 그릇/숟가락·달·치아·체온계·세척 비누·보관 용기. [그림 모음](evidence/art-gallery.png).
- 이유식과 수유, 세척과 모유 보관, 치아와 건강을 구분한다. 모호한 제목은 구름 대신 책을 기본으로 사용한다. 기존 홈의 명시적 그림 7종은 유지했다.
- 같은 수면 그림이 반복되는 방법/고민 목록은 작은 제목과 조건이 먼저 보이는 간결한 카드로 표시한다. 장식 이미지는 접근성 트리에서 제외한다.
- 설명 문장마다 붙던 `01/02/03` 번호를 백과에서는 제거하고 문단으로 읽는다. **실제 진행 순서에만 번호**를 둔다. 다른 탭의 기존 번호 표시 기본 동작은 유지한다.
- 수치와 조건은 여러 색 상자 대신 **항목명 / 값** 행으로 정리하고 큰 글씨에서는 한 열로 바뀐다. 본문 15px·보조 13px, 루트 16px·입력 최소 16px·주요 조작 최소 44px 기준은 유지한다.
- 긴 원문을 임의의 첫 문장으로 자르거나 자동 의학 요약을 만들지 않았다. 제목/보조 문구를 줄이고, 자세·재료·대처법처럼 고를 수 있는 설명을 선택해서 읽도록 했다.

## 카테고리별 결과

| 카테고리 | 펼침/읽기 개선 |
|---|---|
| 월령 요약 | 기존 핵심 발췌·강조·전체 원문을 보존. 안내 문구 중복을 줄이고, 하위 발달/놀이/수면/먹기 글은 자연스러운 문단으로 표시 |
| 발달 체크 | 영역별 딸랑이/놀이/책/구름으로 구분. 요약 배지와 각 항목에 반복되던 이모지를 줄이고, 항목 제목·관찰 설명·날짜 기능을 분리. 큰 글씨에서 진행 요약이 겹치지 않게 정리 |
| 추천 놀이 | 짧은 제목·시간/난이도 → 놀이 방법 → 준비물/살펴볼 발달/연령의 표 순서. 반복 칩 상자와 모든 문장의 번호 제거 |
| 이유식 | 재료를 분류별로 고르고 상세를 펼침. 단계 수치는 선택해 확인. 조리·주의·메뉴를 구분하며 알레르기 응급 증상은 패널 안에서 바로 표시 |
| 수면 | 참고 수치는 선택해 열기. 방법의 설명 → 주의점 → 진행 순서, 장점은 추가 펼침. 방법 목록에서 반복 그림을 줄임. 밤 수면 합계를 통잠으로 읽지 않도록 설명 추가 |
| 수유 | 수유량/횟수는 참고 수치로 선택해 열기. 자세는 이름/적용 맥락을 먼저 표시하고 필요한 설명만 펼침. 트림·세척·보관·상황별 안내의 제목과 그림을 구분 |
| 치아 | 실제 아기 치아 수처럼 보이던 월령 계산을 ‘월령별 참고’로 명확히 표시. 반복 치아 이모지/별점식 효능 표시 제거. 이앓이 대처·FAQ는 항목 선택, 양치/진료는 짧은 절 제목으로 구분 |
| 건강 FAQ | 기존 요약·필요 행동·금기·진료 조건을 모두 유지. ‘살펴볼 것 / 피할 행동 / 진료·도움’으로 제목을 줄이고 색/경계로 구분. 긴급 조건과 119는 접힘 속에 새로 숨기지 않음 |

상위 카드의 기존 읽기 키는 유지했다. 새 네이티브 하위 접힘은 화면을 다시 열 때 초기 상태일 수 있으며, 더 세밀한 이어 읽기는 후속 5단계에서 추적한다.

## 함께 교정한 명확한 안내 문제

가독성을 정리하며 확인한 다음 6곳은 원문 보존의 예외로 명시적으로 교정했다. 나머지 원문·수치·조건·주의 문장은 접근 가능하게 보존했다.

| 문제 | 교정/근거 |
|---|---|
| 저월령 이유식 시작을 ‘4~6개월이 좋음’으로 추천 | 생후 6개월 무렵의 준비 신호와 개별 시작 안내로 교정. [CDC](https://www.cdc.gov/infant-toddler-nutrition/foods-and-drinks/when-what-and-how-to-introduce-solid-foods.html) |
| 옆으로 누워 수유한 뒤 아기를 눕히지 말라는 안내 | 재울 때는 등을 대고 단단하고 평평한 별도 잠자리로 옮기는 안내로 교정. [NIH 수유·수면](https://safetosleep.nichd.nih.gov/safe-sleep/breastfeeding), [NIH 잠자리](https://safetosleep.nichd.nih.gov/reduce-risk/safe-sleep-environment) |
| 이앓이 젤을 일괄적으로 바르라는 안내 | 벤조카인/리도카인 성분을 영유아 이앓이에 사용하지 않도록 교정. 경고는 대처법의 하위 설명에 숨기지 않음. [FDA](https://www.fda.gov/consumers/consumer-updates/safely-soothing-teething-pain-infants-and-children) |
| 이앓이에서 ‘38도 이하’ 표현 | 38°C 이상 발열을 이앓이로 단정하지 않도록 경계를 명확히 함. [NHS](https://www.nhs.uk/baby/babys-development/teething/baby-teething-symptoms/) |
| 첫 이 이후 치약 없이 물로만 닦아도 된다는 안내 | 소량의 불소 치약 사용 안내로 일치시킴. [NHS 양치](https://www.nhs.uk/baby/babys-development/teething/looking-after-your-babys-teeth/) |
| 양치 뒤 물/거즈로 다시 닦으라는 안내 | 불소가 남도록 물로 다시 헹구지 않는 안내로 교정. [NHS 양치](https://www.nhs.uk/baby/babys-development/teething/looking-after-your-babys-teeth/) |

관련 항목에 실제 참고 자료 링크를 연결했다. 전문가 승인/검수 상태는 추가하지 않았다. 이는 **전체 의료 데이터 검증 완료가 아니다.** 수면 방법별 기간/연령·수유/소독 수치·이유식 단계와 영양·치아 시기 등 기존 C2~C7 대조 과제는 남아 있다.
