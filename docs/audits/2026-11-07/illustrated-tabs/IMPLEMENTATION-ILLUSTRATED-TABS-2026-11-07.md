# 홈의 디자인을 나머지 탭으로 확장 — 2026-11-07

사용자가 승인한 밝은 하늘색·살구색과 자체 구름/젖병 일러스트를 백과·꿀팁·기록·설정에 확장했다. 홈의 본문·대표 추천·그림 배치는 유지했다. 이번은 기존 계획 3·4단계의 **공통 표현·그림·선택 상태·확대 대응 개선**이다. 모든 긴 가이드의 목록/상세 전환이나 저장한 글 기능까지 완료한 것은 아니다.

## 화면별 변경

| 화면 | 반영 |
|---|---|
| 공통 상단 | 백과/설정은 구름, 기록은 기록장, 꿀팁은 외출 구름. 고정 56px 장식 그림과 제목/아기 정보/검색을 정렬. 기존 제목 22px·본문 15px·보조 13px 유지 |
| 백과 | 월령 요약을 옅은 하늘색 카드로 표시. 가이드의 발달·놀이·잠·먹기·건강/치아 주제를 그림으로 구분. 펼친 카드의 파란 테두리와 상세 원문·읽기 상태 유지 |
| 꿀팁 | 저월령의 상황 4개에 젖병·구름·놀이·수면 그림 적용. 주제 선택도 같은 그림 체계로 정리. 일반 팁은 살구색 배경과 구름으로 표시. 기존 방법/주의/출처·월령별 일과/필터 유지 |
| 기록 | 성장/접종 전환에 기록장/건강 그림 사용. 최근 수치·측정일은 실제 기록 그대로 표시. 큰 글씨에서 수치와 선택 버튼을 세로로 재배치 |
| 접종 | 하늘색/살구색과 공통 표면을 사용. 작은 화면·큰 글씨에서 목록 필터, 펼친 백신, 날짜 입력, 저장/취소/삭제 확인이 넘치지 않게 조정. 선택 날짜를 별도 텍스트로도 표시 |
| 설정 | 선택 아이콘의 밝은 배경과 탭 표현 통일. 화면·글자 크기에 따라 탭 열 수가 조정됨. 중복 구름을 빼고 상단 한 곳을 시각적 중심으로 유지 |
| 아기 선택 | 기록 카드·선택 시트는 고정 크기 사진과 가변 본문으로 배치. 좁은 화면에서는 변경 표시가 다음 줄로 이동. 긴 이름·복수 아기·키보드/포커스 복귀 보존 |

`TopicArtwork`는 홈의 `GuideArtwork` SVG를 재사용한다. 외부 이미지 다운로드가 없고 장식 이미지는 접근성 트리에서 제외한다. 제목에 따른 그림은 탐색용 시각 표시이며 건강 상태를 판정하지 않는다. 그림이 본문을 밀어내는 좁은 가이드 카드에서는 그림을 숨긴다. 새 반복 애니메이션은 추가하지 않았다.

## 꼼꼼히 확인하고 수정한 부분

- `.surface-card`의 CSS가 펼침 테두리를 덮는 문제를 고쳐 실제 선택 색이 표시되게 했다. 모션 감소 설정에서는 해당 색 전환도 즉시 적용한다.
- 설정 탭·최근 측정값·기록/접종 선택·복수 아기 선택은 200% 글씨에서 고정 열이 지나치게 좁아지지 않도록 재배치했다.
- 날짜 입력은 브라우저의 기본 컨트롤을 유지하되 선택한 날짜를 줄바꿈 가능한 별도 문장으로도 제공한다.
- 아기 사진/전환, 성장 측정일·단위·값, 접종 완료 기록, 조건·주의·긴급 안내·출처는 보존했다. 저장/삭제·수치 계산·DB/인증 로직은 변경하지 않았다.

## 실제 적용

- 실제 저장소 `D:/workplace/03-INFANTPEDIA`에 소스 12개·검사 스크립트 2개를 반영했다. 반영 전 원본 해시와 격리 검증본 해시를 대조했다.
