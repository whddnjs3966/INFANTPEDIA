# 콘텐츠 검증·UI 개선 1차

작성: 2026-11-04. 저장소: `D:/workplace/03-INFANTPEDIA`. 최초 콘텐츠 검증 계획의 C1/C2와 FAQ 시각화부터 반영했다. 운영 DB 변경·배포·의료 전문가 검수는 수행하지 않았다.

## 일과표

- 0~3개월은 고정된 기상·취침과 밤중 수유 없는 시각 예시 대신, 아기의 신호에 따른 낮/밤 흐름으로 바꿨다. 낮에는 수유·돌봄·짧은 교감·잠, 밤에는 잠·각성 시 상태 확인과 필요한 수유·다시 안전한 잠자리로 이어진다.
- 그림의 칸 길이가 시간 비율이 아님을 표시했다. 모든 아기가 같은 시간에 먹거나 정해진 밤 수면을 채워야 한다는 의미를 제거했다.
- 4~12개월의 참고 일과는 00~24시의 ‘밤 시간/낮잠/수유·식사/놀이·돌봄’ 별도 줄로 표시한다. 밤은 빗금, 활동은 종류별 색, 소요시간 범위는 옅은 색으로 구분한다.
- 활동의 명시된 수치 소요시간만 그린다. 다음 활동까지 직전 수유/놀이로 채우지 않으며, 취침 뒤의 긴 구간을 실제 연속 수면으로 그리지 않는다. 자정 넘김을 분리하고 소요시간이 없는 활동은 추측해 막대를 만들지 않는다.
- 검수 전인 총 수면 범위는 요약 카드에서 제외했다. 대신 예시에 적힌 낮잠·수유/식사 항목 수와 그 의미를 표시한다. 월령별 실제 권고 횟수로 오인하지 않도록 안내한다.
- 활동 필터와 펼침 상태, 같은 월령 가이드 연결을 유지했다. 저월령 반복 흐름은 색 외에도 아이콘·순서·문구로 읽을 수 있다.

## FAQ·검색

- 증상 검색·빠른 검색어·주제별 질문 수를 중심으로 재구성했다. 긴급 상황 정보/진료·상담과 돌봄/일상 정보의 시각적 구분을 유지하되, 질문 분류가 실제 상태 진단이라는 인상을 줄였다.
- 위험 신호와 국내 119 연결은 주제/검색/긴급 필터 및 검색 결과가 없어도 계속 보인다. 전화 링크는 사용자 선택 시에만 동작한다.
- FAQ 18개를 ‘요약 → 이렇게 살펴보기 → 피하기 → 진료/도움’으로 구조화했다. 긴 문단에서 행동 안내를 찾기 쉽게 하고 수치·약물의 임의 사용을 줄였다.
- 구조화한 안내와 검색에 쓰이는 전체 답변은 같은 내용으로 검증한다. 검색 결과·상세에서도 긴급도, 자료, 전문가 검수 대기와 행동 블록이 보존된다.
- 근거 자료의 연결/대조일과 의료 전문가 검수 상태를 별도로 보여 준다. 현재 자료 연결 FAQ는 18/89개이고 전문가 검수 완료는 **0개**다. 출처를 추가했다고 검수 완료 배지를 표시하지 않았다.
- 실제 온라인 팁 분류(`sleep_tips` 등)를 검색의 가이드 링크 매핑에 반영했다. 원문이 바뀐 자료에 기존 검토 표시가 자동 승계되지 않도록 했다.

## 공개 DB 처리

앱의 `reviewedPublicContent`는 두 자료의 **테이블·ID·정확한 기존/교정 내용**을 대조해 교정본과 근거를 반환한다. 조회·온라인 백과/꿀팁·검색이 같은 함수를 사용한다. 미래 편집으로 본문이 바뀌면 이 교정과 검토 상태를 자동 부여하지 않는다. 이는 앱 표시 교정이며 운영 데이터가 이미 바뀌었다는 뜻은 아니다.

운영 반영용 `sql/content/20261104_content_safety.sql`을 준비했다. 두 행 중 하나라도 예상 원문과 다르면 트랜잭션 전체를 중단하며, 이미 같은 교정본이면 반복 실행이 가능하다. 메모리 DB에서 이 조건과 전체 롤백을 확인했다. 기존 위험 문구를 복원하는 자동 롤백 파일은 제공하지 않는다. 운영 반영은 원문 재확인·백업·대상 diff 검토 후 별도로 진행한다.

## 검증 결과

- `npm run check:content-safety`: **15개 통과**. 13개월 자료 존재, 저월령 시각 제거, 실제 소요시간·자정·잘못된 입력, FAQ ID 89개 보존, 18개 원문/구조화 답변 일치, 임의 전문 검수 승격 방지, 검색 전파, 공개 원문 revision 및 SQL 조건 검사.
- 격리 Chrome 브라우저: **9개 시나리오 통과**. 낮/밤 흐름, 활동 필터/복귀, 그래프 의미, FAQ 행동 블록, 근거/전문 검수 구분, 빈 검색/긴급 필터, 검색 상세, 온라인 팁 교정 표시, 모바일/다크/키보드/확대.
- 기존 읽기 이동 10개·기록 22개·공유 중지 10개 통과. 이번 총 검사 항목 **66개**다. 의학적 검수 건수가 아니다.
- 타입 검사·ESLint·webpack 프로덕션 빌드 통과. middleware 사용 중단 예정 경고는 기존 상태로 남아 있다.
- 브라우저는 360/390/430px, 줄인 모션, 다크 모드와 200% 루트 글자 확대를 확인했다. 실제 모바일 OS/스크린리더 검증을 대신하지 않는다. 실행 오류 0개.
- 격리 브라우저 검사는 이전에 읽은 공개 스냅샷을 fixture로 공급했다. 추가로 실제 사용자용 3219 앱에서 2개월 리듬·실제 공개 팁 교정 표시·FAQ를 확인했다(66개 집계와 별도). 실제 공개 데이터는 GET만 허용했고 쓰기와 개인 기록 접근은 차단했다. QA 서버는 종료하고 사용자용 개발 서버 3219는 열어 두었다.
