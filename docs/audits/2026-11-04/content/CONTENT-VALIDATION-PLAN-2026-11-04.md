# INFANTPEDIA 육아·의료 데이터 전수 점검 및 수정 계획

작성: 2026-11-04 (Asia/Seoul)

**목표:** 월령별 예시를 모든 아기의 정상 기준처럼 제시하지 않고, 수면·수유·이유식·의료 정보를 실제 근거와 일치시키며 홈/백과/꿀팁/검색/기록에서 같은 내용을 보여 준다. 기존 관리자 기능 개발보다 이 콘텐츠 검증을 우선한다.

현재는 **전수 목록화 + 구조 검사 + 우선 위험 문구의 공식 자료 대조**를 수행했다. 모든 문장에 대한 원문 대조와 의료 전문 검수가 끝난 상태는 아니다. 최초 계획 뒤 앱·정적 데이터·seed 1차 교정을 반영했다. 운영 DB는 적용 전이며, 최신 결과는 [UI·검증 개선 1차](ui-round1/IMPLEMENTATION-CONTENT-UI-ROUND1.md)를 참고한다. 아래 건수는 최초 전수 목록 기준이며 수정 후 인벤토리는 ui-round1 폴더에 별도로 보존한다.

정적 자료 11개 파일의 값 8,415개를 목록화했고, 그중 검토 대상 콘텐츠 필드 5,595개에는 공통 값의 월령별 반복과 숫자가 포함된다. 고유 텍스트는 2,181개다. **이는 의학적 주장 8,415개를 검수했다는 뜻이 아니다.** 공개 DB는 804개 필드로 별도 등록했다.

공개 DB는 익명 공개 키로 위 콘텐츠 표만 GET 조회했다. 아기·계정·공유 기록은 조회하지 않았다. `growth_standards`, `vaccination_schedule`는 공개 REST에서 HTTP 404여서 실제 존재/공개 상태를 확인하지 못했다. 0행 또는 삭제된 표라고 결론 내리지 않는다. 앱의 정적 성장/백신 데이터는 계속 점검한다.

## 2. 2개월 시간표의 구체적인 문제

현재 예시는 07시 기상, 20시 취침이다. 마지막 수유가 19시에 있고 밤중 수유/깸 항목이 없으며, 낮 시간 수유는 5개다. 홈의 공개 월령 데이터는 6~7회라고 표시하므로 화면끼리도 의미가 맞지 않는다. 이를 어느 한 수유 횟수로 강제 통일하지 않고, 수유 방식·신호와 건강 상태를 반영하는 예시로 바꿔야 한다.

또한 시간 막대는 활동의 `duration`을 읽지 않고 다음 항목까지 같은 색으로 칠한다. 수유 20~30분이 막대에서는 1시간으로 보일 수 있고, 취침 뒤는 다음 06시까지 단일 수면으로 표시된다. 데이터 문구만 수정하면 이 오해가 남는다.

수정할 목표는 다음과 같다.

- 취침 구간과 실제 연속 수면을 구분한다. 야간 각성/수유가 있을 수 있는 구간을 표현하고 특정 야간 수유 시각이나 횟수를 정답처럼 고정하지 않는다.
- ‘2개월은 통잠 불가능’ 또는 ‘2개월이면 통잠 가능’을 기본 정상 기준으로 삼지 않는다. 개인차가 있으며 저월령의 야간 수유 필요성을 빼놓지 않는다. [NHS 수면 안내](https://www.nhs.uk/baby/caring-for-a-newborn/helping-your-baby-to-sleep/)
- 시작/종료, 날짜 넘김, 소요시간 범위, 비정기 항목, 미정 구간을 구조화한다. 표시되지 않은 시간을 직전 활동으로 자동 채우지 않는다.
- 참고 일과·권고 범위·아기의 실제 기록을 시각적으로 구별한다. 총 수면량을 단순히 취침~기상 시간으로 계산하지 않는다.
- 낮잠 4~5회 표시와 예시 4회는 범위 내이므로 확정 오류가 아니다. 예시와 범위가 다르다는 이유만으로 모든 월령을 기계적으로 바꾸지 않는다.

## 3. 실행 순서 — C0~C7

기존 개발 TODO 1~9와 혼동하지 않도록 콘텐츠 작업은 C번호로 추적한다. 한 번에 일괄 치환하지 않고 각 묶음마다 근거·수정 전후·화면 일치·검사 결과를 남긴다.

| 순서 | 작업 묶음 | 완료 조건 |
| --- | --- | --- |
| C0 | 전수 목록·실제 공개 데이터 스냅샷·초기 위험 검사 | **이번 완료.** 누락/조회 실패를 분리하고 원문/해시/ID/검수 상태를 기록 |
| C1 | P0 안전 문구 우선 교정 + 근거/검수 상태의 공통 최소 모델 | CA-001~006 처리. 옆잠·경사 수면·질식 형태·어린 영아 발열·국내 응급번호·분유 치료 개념을 원문과 대조. 고위험 세부 지시가 불확실하면 비노출/안전 안내로 대체하며 검수 완료로 표시하지 않음 |
| C2 | 일과표·수면·수유의 월령별 정합성 | **0~3개월을 먼저**, 4~6, 7~9, 10~12 순서. 시간 데이터/막대를 함께 고치고 같은 월령의 홈·백과·꿀팁·검색이 모순되지 않는지 확인 |
| C3 | 이유식·재료·모든 주간 식단 | 준비 신호·약 6개월 기본 안내를 정리한 뒤 28재료와 133식사를 순서대로 대조. 알레르기/질식·철분·단위·완성량·조리/보관 조건까지 검토 |
| C4 | 건강 FAQ 89개 전수 | 발열 → 호흡기 → 소화 → 피부 → 일반. 질문별 각 주장·월령·위험 신호·금기·행동 지침과 실제 근거를 대조. 검수자는 해당 분야 자격과 날짜를 기록 |
| C5 | 성장·예방접종·치아·발달·놀이·기타 팁 | 원표 수치/계산법, 국내 접종 일정/제품/차수, 양치·불소, 관찰/진단 구분, 나머지 팁/원더윅스 근거를 검토. 미확인 주장을 그대로 공식 기준으로 승격하지 않음 |
| C6 | 단일 콘텐츠 원본·DB/seed/검색/캐시 정합성과 자동 검사 | 동의어·중복 자료를 공통 주장의 ID로 연결. 모든 진입점에서 같은 버전/근거/주의사항을 확인. 실제 DB의 sleep_tips/feeding_tips 등 분류와 검색의 sleeping/feeding 매핑 불일치도 교정. 수정 내용의 재등장을 막는 검사 추가 |
| C7 | 전문 검수·최종 화면 검증·콘텐츠 공개 | P0 미해결 0, 고위험 항목의 전문 검수/비노출 결정, 전체 검토 대장 처리 완료, 온라인/오프라인 최신 상태 확인 후 공개. 실제 DB 변경은 백업·변경 전 조건·대상 행 diff·롤백을 준비해 별도 적용 |

수정은 C1→C2→C3 순으로 시작한다. 이 계획 작성 뒤 관리자 기능 8번으로 자동 복귀하지 않는다. 일정은 검토 건수와 전문가 회신을 기준으로 잡고 임의 완료 날짜를 약속하지 않는다.

## 4. 영역별 검토 항목

### C1/C4 — FAQ와 의료 안내

- **발열:** 나이의 정의(만 개월/생후 일수), 측정 기기·부위·값, 즉시 진료 신호, 접종 직후 예외, 처짐/탈수/호흡곤란, 해열제의 목적·성분·제형·농도·간격·최대량·금기. 숫자만 보고 처방처럼 행동하게 하지 않는다.
- **호흡기:** 호흡곤란/청색증/무호흡/수유 어려움의 응급 경로, 코막힘 돌봄, 흡인기·식염수·습도·수면 자세, 감기/중이염/폐렴 등의 진단 단정 여부와 약물 제한.
- **소화:** 정상 게워냄과 반복 분수토/담즙성 구토의 구분, 탈수·혈변·변비/설사, 임의 분유 변경/식이 제한 위험, 우유 단백 알레르기와 유당 문제의 구분, 생리적 변화와 질병의 경계.
- **피부:** 흔한 신생아 피부 변화, 습진·기저귀 발진·진균 문제, 감염/자반 등 진료 신호, 약물 사용 부위/기간/제형, 과도한 소독·민간요법의 근거.
- **일반:** 성장·황달·구강·눈/귀·경련·예방접종·영양제·검진·응급 안내의 나이/국가/제품별 조건. ‘정상’, ‘걱정하지 않아도’라는 결론 앞에 위험 신호가 빠지지 않았는지 확인.
- FAQ의 긴급도는 질문 단위 고정 배지만으로 끝내지 않는다. 같은 질문이라도 나이와 증상에 따라 행동이 달라지는 구조를 검토한다. 태그/월령 필터 때문에 저월령 응급 정보가 빠지지 않게 한다.
- 한국의 약품은 식약처 허가사항·제품 농도를 기준으로 확인한다. NHS의 영국 약품 시작 연령을 한국의 정답으로 복사하지 않는다.

각 질문은 [FAQ-REVIEW-CHECKLIST.md](FAQ-REVIEW-CHECKLIST.md)에 89개 모두 미검수로 등록했다. ‘근거 링크가 생김’과 ‘답변의 모든 주장이 일치함’과 ‘의료 검수 완료’를 별개로 처리한다.

### C2 — 일과·수면·수유

- 모든 월령의 시작·종료·중복/공백·자정 넘김·수유와 수면 겹침·낮잠 횟수/합계·야간 각성·총 수면의 의미를 점검한다.
- 깨시·수면시간·수유량·수유 횟수는 근거가 있는 범위인지, 측정 대상과 개인차가 표시되는지 확인한다. 분유 mL 범위를 직접 모유 수유 아기의 섭취 목표로 쓰지 않는다.
- 신생아 성장/수유의 개별 의료 지시가 시간표보다 우선한다. 미숙아·성장 부진·질병·혼합 수유를 일반 일정으로 덮지 않는다.
- 밤중 수유 감량/중단·물로 대체·꿈수유와 수면교육을 단순 월령만으로 권고하지 않는다. 수면교육의 효과·기간 단정과 건강 조건을 원문 연구 대상과 대조한다.
- 안전 수면, 안고 달래기, 깨어 있을 때의 터미타임을 구분한다. 속싸개 중단을 ‘뒤집기 성공일’로만 늦추지 않는지 확인한다.
- 모유·분유 보관과 조제는 종류·온도·시작 시점·먹던 것·재가열 조건을 별개로 다룬다. 세척/소독은 기구 제조사 지시와 대상 아기 조건을 함께 확인한다.

### C3 — 이유식·식단

- 기본 시작 시기와 목/자세/삼킴 등 준비 신호, 모유/분유의 역할, 철분을 포함한 영양 구성을 함께 검토한다. ‘4개월 단계’만 바꾸고 관련 식단을 남기지 않는다.
- 재료 28개 × 월령별 등장 위치를 대조한다. 소고기 7개월부터라는 표와 6개월 소고기 식단의 모순은 임의 지연이 아닌 근거 기준 재설정으로 해결한다.
- 알레르기 식품은 형태·조리·소량·섭취 이력·기존 알레르기/습진 등 위험군별 조건을 분리한다. `allergyRisk: false`가 ‘알레르기가 생기지 않는 식품’으로 보이지 않는지도 확인한다.
- 식단의 소개 순서와 ‘새 재료 하나씩’ 안내가 실제로 맞는지 확인한다. 기존에 먹어 본 재료가 있다는 예시 전제가 있다면 명시한다. 식단 예시를 알레르기 검사 일정으로 오인시키지 않는다.
- g/ml/티스푼/큰술, 불린 쌀/생쌀/완성죽, 원재료/조리 후 중량을 분리한다. 별도 근거 없는 단위 환산으로 칼로리나 영양량을 만들어내지 않는다.
- 단백질·철분·지방·식품 다양성과 우유 섭취를 함께 본다. 메뉴 이름이 건강해 보인다는 이유로 영양 균형을 확인했다고 처리하지 않는다.
- 꿀·생우유 음용/조리 구분·주스/소금/당·통견과류·질식 위험·가시·비살균/날음식·보관/재가열까지 확인한다. 보리차를 물과 동일한 기본 수분 공급원으로 제시하는 근거도 검토한다.

### C5 — 성장·접종·치아·발달·놀이

- **성장:** WHO/국내 적용 원표, 성별·신장/누운키·체중·머리둘레·생후 정확한 나이·교정 연령·측정 오차. 중앙값 13행과 범위 78행의 모든 숫자를 대조한다. 공식 L/M/S 또는 검증된 계산법 도입과 ‘추정 백분위’ 유지 여부를 판단한다. 자의적 성장 급증 임계값을 의학적 판정으로 사용하지 않는다.
- **접종:** 2026 국내 지침의 실제 제품/국가사업 범위, 로타의 주/일 상한, 인플루엔자 첫 해 차수, 12개월 이후 추가 일정/연결. 권고/접종 가능성 계산과 실제 받은 과거 접종 기록 입력은 분리한다. 차수 모델을 바꿀 때 로컬/서버 검증과 기존 기록 호환성을 확인한다.
- **치아:** 첫 치아, 불소 농도/양/보호자 지도, 맹출 개인차, 실제 발열을 이앓이로 오인시키는 기준, 첫 치과 방문/진료 신호를 점검한다.
- **발달:** 169개 항목의 나이·행동 정의·범위·교정 연령과 출처. 관찰 달성률을 발달 점수로 오인하지 않게 하고, 미도달/기술 소실 시 적절한 상담 안내를 정한다. K-DST 등의 문항을 임의 수정해 공식 도구처럼 쓰지 않는다.
- **놀이·팁:** 터미타임 감독/수면 구분, 장난감 작은 부품·줄·자석·전지·물·낙상·과열·큰 소리 등 맥락별 위험, 보행 보조의 종류, 시간·효과 주장과 개인차를 확인한다.
- **원더윅스:** 임상 예측 근거를 별도로 확인하고, 근거가 부족하면 일정 확정/증상 원인 설명으로 쓰지 않는다. 정해진 도약기와 아기의 실제 건강 문제를 연결해 진료를 미루게 하지 않는다.

## 5. 자료의 우선순위와 검수 방식

1. 국내 질병관리청·식약처·보건복지부/국민건강보험공단·소방청의 해당 주제 최신 원문을 우선한다.
2. 국내 소아청소년과/소아치과 등의 관련 학회 지침을 확인한다. 학회 이름만 달고 문헌이 없는 기존 주장은 검증 완료로 바꾸지 않는다.
3. 국내 원문으로 충분하지 않으면 WHO·AAP·CDC·NHS 등의 원문에서 대상/국가/예외를 비교한다. 자료 간 차이는 임의 절충하지 않고 사유를 기록한다.
4. 근거가 제한적인 수면 훈련·발달 시점·놀이 효과는 연구의 대상과 한계를 확인하고, 필요한 경우 효과 단정을 삭제하거나 참고 예시로 제한한다.
5. 소아청소년과 전문 검수, 소아치과 검수, 영양 관련 검수는 실제 수행자와 날짜를 기록한다. 자동 검사나 AI의 자료 대조만으로 ‘의료 검수 완료’를 만들지 않는다.

이번에 찾은 공식 원문 24개와 적용 범위는 [SOURCE-REGISTER.md](SOURCE-REGISTER.md)에 있다. 안전 지침이 없는 부분을 추측으로 채우지 않고 `근거 추가 확인` 상태로 남긴다.

## 6. 검토 대장과 콘텐츠 모델

의미가 독립된 주장 하나마다 아래를 관리한다. 기존 배열 인덱스는 위치 참고용이며 장기 ID로 사용하지 않는다.

```text
claimId / contentId / revision / locale
주장 원문 / 수정안 / 노출 화면 / 정적 파일 / DB table+row ID
대상: 나이·측정법·수유/음식 형태·질병/위험군·국가/제품
claimType: 의료 권고 | 참고 범위 | 일과 예시 | 관찰 | 미확인
source: 기관·문서명·URL·관련 절·개정일·확인일
evidenceStatus: unmapped | checking | matched | conflicting | insufficient
reviewStatus: pending | evidence_checked | clinician_reviewed | withheld
수정 사유 / 위험도 / 검수자·자격·검수일 / 재검토 기한
검사 결과 / DB 변경 전후 조건 / 공개 버전 / 롤백 방법
```

식단은 재료/조리법/기본 제공량을, 일과표는 시간 범위와 비정기 야간 구간을 별도 모델로 갖는다. 수치가 없는 영역을 마치 정확한 분/그램 수치가 있는 것처럼 자동 생성하지 않는다. 의료 정책의 숫자를 여러 파일에 복사하는 구조를 줄인다.

검토 중인 대장은 제품의 임상 검수 배지와 분리한다. 원문이 수정되면 관련 버전과 검토 상태도 재평가하며, 검수 당시와 다른 문장이 검수 완료 상태를 그대로 물려받지 않게 한다.

사용 시나리오는 0/1/2/3개월과 월령 경계, 건강한 만삭아/미숙아·교정 연령/성장 상담 중, 모유/분유/혼합, 기존 알레르기, 12개월 전후, 제품별 접종을 포함한다. 위험한 상황을 일반 돌봄 문구로 안심시키는지 확인한다. 개별 건강정보를 새로 수집하는 기능을 이 계획 때문에 임의 추가하지 않는다.
