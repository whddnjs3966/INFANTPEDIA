# 탭·카드·안내 블록별 UI 점검표

2026-11-05 · 계획 문서: [전체 단순화 계획](UI-UX-SIMPLIFICATION-PLAN-2026-11-05.md)

‘확인’은 현재 코드/로컬 화면의 검토를 뜻한다. 개선 구현 완료 표시는 아니다. 한 행은 카드·행·탭·안내 블록 단위이며 실제 콘텐츠 항목 전체 개수를 뜻하지 않는다. 일반 화면은 합성 데이터 브라우저 확인, 로그인 후 서버 상태·파기·관리자 및 현재 미사용 컴포넌트는 소스 확인으로 구분한다.
