## 1. 이번에 바뀐 화면

### 꿀팁 — 시간대별로 살펴보기

시간이 작은 글씨로 카드 안에 반복되던 구조를, 시간 열이 먼저 보이는 간결한 목록으로 바꿨다.

1. **오전 / 오후 / 저녁 선택**: 기본은 오전이다. 06–12시, 12–18시, 18–24시를 함께 표시한다. 해당 구분은 예시 시각을 묶은 것으로, 아기에게 권하는 기상·수유 시간이 아니다.
2. **하루 전체**: 모든 활동을 시간 순서대로 볼 수 있다. 전체 보기에서도 시간대 제목과 구분선을 유지한다.
3. **시간 → 활동 → 종류·소요시간**: 시간과 제목은 16px, 보조 정보는 14px로 표시한다. 큰 아이콘 상자와 중복 소요시간 문구를 줄였다. 이유식의 ‘1회’ 같은 별도 의미는 유지한다.
4. **필요한 설명만 펼치기**: 한 활동을 누르면 16px 돌봄 팁이 펼쳐진다. 선택한 시간대·활동 필터·펼침 상태는 같은 읽기 세션에서 돌아와도 유지된다.
5. **수유·식사 / 잠 / 놀이·돌봄 필터**를 시간대와 조합할 수 있다. 결과가 없으면 시간대 전체 보기와 필터 초기화를 제공한다.
6. **0–3개월**은 시계 기준 탭 없이 기존의 신호 반응 돌봄을 유지한다. 4–12개월 전체 보기에서 기존 활동을 모두 보존했다. 원자료에 없는 야간 활동이나 소요시간을 만들지 않는다.
7. 글자가 커지면 시간과 활동을 세로로 배치하고 시간대 버튼도 줄을 바꾼다. 키보드 조작·선택 상태·설명 펼침 상태를 제공하며 색과 함께 텍스트로 구분한다.

## 2. 앱 전체 가독성 점검과 반영

주요 5개 메뉴와 수면·수유·이유식·치아·건강 FAQ·원더윅스·개인정보 화면을 포함한 **11개 경로 × 밝은/어두운 모드**를 확인했다. 자동 측정은 화면에 렌더링된 직접 텍스트의 글자 크기와 단순 배경의 색상 대비를 확인한다. 접힌 내용 전체, 실제 스크린리더, 복잡한 배경·이모지의 시각 품질을 모두 판정하는 검사는 아니다.

| 영역 | 확인한 문제 | 이번 반영 |
| --- | --- | --- |
| 일과 목록 | 시간 12px, 제목 14px, 큰 카드 13개 반복 | 시간·제목 16px, 보조 14px, 시간대별 목록 |
| FAQ | 분류·검수 안내 11px, 일부 행동 안내 14px | 질문·행동 본문 16px, 검수·출처·긴급 안내 14px |
| 공통 긴 글 | 본문 14px, 문장 번호 10.5px, 밝은 청록색 번호 | 본문 16px/줄높이 1.75, 번호 14px, 진한 브랜드색 |
| 공통 강조 | 주의 단어의 밝은 주황색 | 밝은 화면에서 더 진한 주황색, 다크에서 밝은 강조색 |
| 원더윅스 | 10.5–13px, 과거 도약 제목과 날짜의 흐린 회색 | 제목 16px, 설명·날짜 14px, 읽을 수 있는 보조색, 본문 투명도 제거 |
| 개인정보 | 본문 13px, 작은 번호와 시행일, 흐린 청록색 | 본문 16px, 번호·시행일 14px, 진한 브랜드색 |
| 이유식 | 비선택 단계·월령·새 재료·알레르기 범례가 흐림 | 단계와 범례의 글자 대비 보완 |
| 치아 | 윗니/아랫니 이름이 흐림 | 공통 보조 글자색 적용 |
| 백과 상단 | 크림 배경의 ‘8개 주제’ 약 4.39:1 | 공통 보조색으로 교체 |
| 공통 글꼴 | 고정 px 크기와 개별 글꼴 지정 | 공통 크기를 rem으로 전환, 로드한 글꼴 변수를 사용 |

기존 Noto Sans KR은 브라우저에서 실제 로드되고 있었다. 글꼴 오류로 판단하지 않았으며, 이번에는 공통 변수 사용과 크기 체계를 정리했다. 기존의 크림색 배경·진한 청록색 중심 배색을 유지한다.

### 배색 판단

| 조합 | 대비비 |
| --- | ---: |
| 본문 `#24312D` / 크림 `#F7F5F0` | 12.42:1 |
| 보조 설명 `#606C65` / 크림 | 5.03:1 |
| 청록 `#0F766E` / 흰색 | 5.47:1 |
| 청록 / 크림 | 5.02:1 |
| 다크 본문 `#F5F5F4` / 카드 `#1C1917` | 16.03:1 |
| 다크 보조 `#B8BDB3` / 카드 | 9.13:1 |

핵심 팔레트를 바꾸기보다, 화면마다 남은 흐린 회색·밝은 강조색을 공통 색상으로 정리하는 편이 일관성과 가독성에 유리하다. 일반 텍스트 대비는 4.5:1, 큰 글자는 3:1을 참고했다. [W3C 대비 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

이번 새 시간대 버튼은 기본 64px 이상, 활동 필터는 48px 이상이다. 48px는 이 앱에서 편하게 누르기 위한 설계 기준이며 WCAG AA의 최소값을 뜻하지 않는다. [W3C 터치 대상 최소 크기 설명](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)

## 3. 앞으로 개선할 순서

### U1. 긴 가이드의 읽기 구조 정리

- 수면·수유·이유식에서 먼저 필요한 핵심 정보를 짧게 요약하고, 세부 설명을 주제별로 펼치는 구조로 통일한다.
- 긴급 행동·금기·진료 기준은 요약에서 함께 보이도록 설계한다.
- 제목 20–24px, 본문 16px, 보조 14px를 공통 기준으로 정리하고 각 화면의 임의 크기·회색을 점진적으로 줄인다.
- 설정 하단 장식 문구 ‘Made with / for parents’는 현재 약 2.37:1(밝은 모드), 2.59:1(다크)로 흐리다. 정보 우선순위는 낮지만 공통 보조색으로 정리할 후보로 남긴다.

### U2. 치아·성장·일과 그래프와 상세 설명 연결

- 치아 그림의 작은 점과 별표를 읽어야 하는 정보로 사용하지 않도록, 치아 이름과 상태를 텍스트 범례/목록으로 함께 제공한다. 자동 측정의 8px 점과 이모지 대비 후보는 실제 의미·표현을 사람이 따로 확인해야 한다.
- 성장 그래프의 축·단위·측정값은 읽을 수 있는 크기와 쉽게 선택할 수 있는 점검 영역을 확인한다.
- 일과 그래프의 활동을 선택하면 같은 시간대와 상세 설명으로 연결하는 흐름을 검토한다. 그래프와 목록의 월령·시각·범례를 일치시킨다.

### U3. 실기기에서 한 손으로 탐색 확인

- iPhone Safari와 Android Chrome에서 아기 변경 → 월령 선택 → 시간대 변경 → 활동 설명 → 가이드 왕복을 점검한다.
- OS 글자 확대, 화면 하단 메뉴 가림, 키보드가 열린 검색, 다크 모드, PWA 안전 영역을 확인한다.
- 부모 사용자에게 특정 시간의 활동 찾기·수유만 보기·도움 정보 찾기를 요청해 잘못 누른 위치와 걸린 시간을 관찰한다.

### U4. 읽기 설정과 공통 스타일 마무리

- 실제 사용성 결과에 따라 큰 글씨 모드의 필요성을 결정한다. 우선 OS/브라우저 확대에서 내용과 기능이 유지되도록 만든다.
- 본문/설명/상태/버튼의 글자와 색상 규칙을 공통화하고, 줄임표·고정 높이 때문에 정보가 사라지는 화면을 추적한다.
- 확대 목표는 200%까지 내용·기능을 보존하는 것이다. 이번 루트 글자 확대 검사는 그중 한 검증 방식이며 전체 접근성 인증을 뜻하지 않는다. [W3C 글자 확대 설명](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)

별도로 콘텐츠 검증의 기존 순서는 **C2 잔여 수유·수면 수치 대조 → C3 이유식·식단 전수 검증**을 유지한다. FAQ 전문 검수 완료는 여전히 0개이며, 이번 UI 개선을 의료 검수 완료로 표시하지 않는다.
