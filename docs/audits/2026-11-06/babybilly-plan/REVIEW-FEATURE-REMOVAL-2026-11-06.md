# 전문가 검수 기능 제거 · 벤치마킹 계획 연결

작업일: 2026-11-06 · 저장소: `D:\workplace\03-INFANTPEDIA`

상태: 로컬 반영·격리 QA·webpack 배포 빌드(23개 페이지)·실제 3219 앱 확인 완료. 운영 배포는 하지 않았다.

## 제거한 기능

- FAQ·검색·꿀팁·일과·식단의 전문가 검수 대기/완료 표시.
- 검수자/검수일 표시와 자료/검수 이력 패널.
- `HealthEvidence.review`의 pending/reviewed 상태와 검수자/날짜 타입.
- 검수자·날짜를 확인해 완료 여부를 판단하던 로직.
- 데이터 목록 생성 도구의 검수 상태·검수자·임상 검수 집계 필드.
- 현재 할 일/개발 계획에 있던 검수 기능·검수대기 검증 작업. 기존 날짜의 감사/인계 문서는 당시 이력으로 보존한다.

FAQ 카드와 검색에는 출처가 있을 때 ‘참고 자료 N개’를 보여주고 상세에서 원문 링크·자료 확인일·참고 범위를 연다. 출처가 없는 항목에 새 대기 배지를 표시하지 않는다. 옛 형태의 데이터가 들어와도 검수자 이름이나 상태를 읽어 배지를 생성하지 않는다.

일반적인 진료·상담 안내의 ‘의료진/전문가’ 표현은 필요한 본문의 일부다. 계정 백업의 등록 검토/복원 미리보기는 별도 기능이므로 보존했다.

## 보존 확인

[본문 무변경 비교](evidence/content-integrity.json)

- FAQ 89개의 질문·답변·월령·긴급도·태그·조건/주의/도움 본문.
- 실용 팁 30종과 13개 월령의 표시용 원문·강조.
- 공개 DB의 안전 교정 두 항목 원문/교정문.
- 출처 URL·자료 확인일과 범위, 119 링크·진료를 늦추지 않는 안내.
- 실제 월령/둘러보는 월령·검색/읽기 상태·기록/계정/백업 동작.

검수 메타데이터를 제외한 변경 전후 객체를 직접 비교했다. 전문가 검수 완료로 바꾼 것이 아니라 기능 자체를 제거했다. 원격 DB 쓰기나 SQL 적용은 없다.

## 검증

- 콘텐츠 표시 12개, 안전/검색/일과 17개, 실용 팁 10개 검사 통과.
- 기능 제거 브라우저 5개, 기존 백과 브라우저 18개, 콘텐츠 브라우저 9개 검사 통과.
- 기존 가독성 검사 8개도 통과했다. 전체 79개 회귀 시나리오이며 재실행은 중복 계산하지 않았다. 현재의 15/13px와 상황별 카드 구조에 맞춰 정리했다. 중첩 설명의 목록 항목을 활동 개수로 세지 않도록 바로잡았다.
- 콘텐츠 목록 생성 도구 실행: 11개 데이터 파일, 9,045개 필드. 승인 상태 집계 없음. 로컬 데이터 모듈만 읽는다.
- 전체 소스 TypeScript·ESLint·배포 빌드 통과. 기존 middleware 파일명 안내는 남아 있다.
- 실제 3219 FAQ·검색 상세·식단에서 검수 UI 없음/참고 자료 유지 확인. 공개 GET 3회, 런타임 오류·데이터 변경 API 요청 0개. [실제 앱 결과](main-app-smoke.json)
