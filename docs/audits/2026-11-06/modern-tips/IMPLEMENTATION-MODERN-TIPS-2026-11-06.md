## 디자인을 바꾼 방향

사용자 피드백은 ‘단순화한 뒤 옛날 앱처럼 보인다’, 특히 ‘신호에 맞춰 돌보기’ 아래 카드가 올드하다는 것이었다. 정보의 요약/상세 구분은 유지하고, 반복된 흐름 그림과 중첩 테두리·큰 색 상자를 없앴다.

- 공통 팔레트를 베이지에서 차분한 중성 배경 `#F6F8FA`, 흰 카드, 진한 본문 `#1F2937`, 청록 포인트로 정리했다. 카드 경계는 얇게, 그림자는 넓고 약하게 조정했다.
- 공통 제목은 28px로 위계를 분명히 하고, 본문 16px·보조 14px를 유지했다. 글자를 작게 줄여서 화면을 축소하지 않았다.
- 월령 선택은 가벼운 흰 캡슐, 하단 메뉴는 아이콘 주위의 작은 선택 표시로 바꿨다. 홈·백과·기록·꿀팁·설정에서 공통 스타일을 확인했다.
- 0–3개월의 낮/밤 반복 그림과 기본 행동 목록 대신 **자주 막히는 상황 4개 타일**을 보여준다. 선택하면 요령·구체적인 행동·주의·자료를 펼친다. 확대 시 한 열로 재배치된다.
- 4–12개월은 시각과 시간대 선택·활동 필터를 유지했다. 하루 그래프는 필요할 때 열도록 옮겼다. 밤 시간과 실제 연속 수면은 구분한다.
- 주제별 팁은 큰 카테고리 상자 4개 대신 한 번에 주제를 선택하고, 두 개의 질문/한 줄 요령을 본 뒤 선택한 상세만 펼친다.
- 무작위 일반 팁은 한 줄 아이디어를 먼저 보여주고 상세를 열도록 정리했다.

기본 행동을 없애려는 이유로 안전 안내를 생략하지 않았다. ‘배고프면 먹이기’ 같은 반복 소개를 줄이고, 자세·환경·준비·중단/도움 조건을 설명한다. 30종을 월령별로 재사용하므로 104개의 독립적인 의료 권고를 새로 만든 것은 아니다.

5개월 식단은 기본 제공 대상에서 제외했다. 이유식은 약 6개월과 준비 상태를 함께 설명한다. 기존 끼니 양·횟수는 닫힌 ‘검토 중인 예시 수치’에 보존해 목표와 구분한다. 메뉴는 완성된 조리법이나 영양 처방이 아니다. 재료량·열량·철분·나트륨·알레르기 조합의 전문 검수는 남았다.

## 원문·검색·오프라인 보호

- DB 편집본은 캡처 ID·월령·분류·제목·본문이 일치할 때만 적용한다. 바뀐 서버 글에 과거 대조 상태를 붙이지 않는다. 원격 DB 쓰기/SQL 적용은 하지 않았다.
- 새 팁은 로컬 검색에서도 찾을 수 있고, 검색 링크로 해당 팁의 전체 본문을 직접 열 수 있다. 최소 월령을 넘지 않은 음식 팁과 알 수 없는 키는 직접 열지 않는다.
- 연결 실패 시 기기에 포함된 해당 월령 팁과 재시도를 제공한다. 옛 무작위 팁 ID를 새 팁으로 오해해 복원하지 않는다.
- 자료 대조와 전문가 검수는 구분한다. 의학적 내용은 검수 대기, 가방 정리 같은 생활 아이디어는 편집 제안으로 표시한다.
- FAQ 89개의 원문·긴급 안내·조건/금기·출처·읽기 상태를 기존 회귀 검사로 확인했다.

## 검증

동일한 390px QA 환경의 2개월 초기 화면 길이는 2778px → 1748px(약 37% 감소)였다. 기본 노출 방식과 콘텐츠도 함께 바뀐 결과이며, 글자를 줄인 효과가 아니다.

- 새 실용 콘텐츠 검사 10개.
- 새 꿀팁 브라우저 시나리오 12개: 월령 13개/104개 주제 팁 접근, 상세/읽기 상태, 시간대·활동 조합, 선택 그래프, 식단, 직접 링크, 오프라인 재시도.
- 320/360/390/430px × 밝은/어두운 화면 × 100%/200% 글자 × 2/4개월 = 32개 조합. 가로 넘침·잘린 컨트롤 없음.
- 기존 콘텐츠 안전 17개, 표시 11개, 읽기/탐색 10개, 백과 브라우저 18개, 콘텐츠 브라우저 9개. **합계 87개 시나리오**, 재실행은 중복 계산하지 않았다.
- 추가 확인: 지연 로딩이 끝난 성장/접종 화면, 설정 5개 실제 패널, 식단 출처 5개와 닫힌 수치 표시, 5개월 활동 분류.
- 전체 소스 TypeScript·ESLint·webpack 배포 빌드(23개 페이지) 통과. 기존 middleware→proxy 안내와 webpack 캐시 경고는 남아 있다.
- 실제 3219 앱에서 공개 팁 8개를 정상 조회하고 새 팔레트·상황 타일·주제 상세·직접 링크를 확인했다. 런타임 오류/데이터 변경 API 요청 0개. [실제 앱 결과](main-app-smoke.json)
