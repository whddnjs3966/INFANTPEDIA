# 폰트 축소·탭 헤더·홈 프로필 카드

작업일: 2026-11-06 · 저장소: `D:\workplace\03-INFANTPEDIA`

사용자 요청: 전체 글자를 조금 줄이고, 각 탭의 이름이 표시되는 최상단과 홈 아기 이름 카드의 디자인을 변경한다.

상태: 로컬 반영·격리 브라우저 검증·배포 빌드·실제 3219 앱 확인 완료. 운영 배포는 하지 않았다.

## 반영한 디자인

| 요소 | 이전 | 현재 |
|---|---:|---:|
| 공통 상단 제목 | 28px | 22px |
| 본문 | 16px | 15px |
| 보조 문구 | 14px | 13px |
| 일반 섹션 제목 | 20px | 18px |
| 홈 아기 이름 | 24px | 20px |
| 입력칸 | 16px | 16px 유지 |

- 루트 폰트와 간격/아이콘/터치 영역 전체를 줄이지 않고, 공통 텍스트 크기 토큰을 조정했다. 루트는 16px이며 200% 확대도 그대로 작동한다.
- 백과·기록·꿀팁·설정의 상단은 작은 주제 아이콘, 제목, 아기/화면 정보를 한 묶음으로 정렬했다. 기존의 작은 문구 위 큰 제목 대신 제목을 먼저 보여준다.
- 백과와 꿀팁의 검색 버튼은 같은 모서리·테두리의 44px 버튼으로 맞췄다. 백과 검색의 월령/돌아가기 주소는 유지했다.
- 홈은 짙은 청록색 프로필 카드, 원형 사진, 아기 이름과 월령/생후일로 바꿨다. 중복되는 ‘의 하루’는 접근성 이름에 보존하고 화면에서는 아기 이름을 먼저 보여준다.
- 홈의 복수 아기 선택은 카드와 어울리는 화살표 버튼 표시로 정리했다. 기존 선택 시트·현재 아기 표시·선택 유지·키보드 포커스 복귀를 보존한다.
- 사진 변경 버튼과 업로드를 유지했다. 카메라 배지는 버튼 안쪽으로 배치해 확대 시에도 넘치지 않게 했다.
- 설정의 현재 아기 배너는 큰 색 상자/성별 이모지 대신 작은 아기 아이콘과 흰 카드로 정리했다. 긴 이름을 잘라내지 않고 줄바꿈한다.
- 개인정보/원더윅스 등 별도 화면의 큰 고정 제목도 22px로 맞췄다.

홈 카드의 흰 보조 문구(80% 불투명도)는 단색 배경과 계산상 대비가 밝은 모드 약 5.61:1, 다크 약 8.08:1이다. 실제 기기 검증을 대신하는 수치는 아니다.

## 확인한 동작과 범위

- 새 브라우저 시나리오 10개: 실제 계산된 글자 크기, 입력칸/버튼 크기, 4개 공통 헤더, 백과 검색 연결, 홈 이름/월령, 복수 아기 전환·새로고침, 선택 아기 사진 저장, 기록 탭 선택 시트, 확대/긴 이름, 런타임/API 확인.
- 다섯 탭 × 320/360/390/430px × 밝은/어두운 모드 × 100%/200% 글자 = **80개 화면 조합**. 가로 넘침·상단 컨트롤 잘림 없음.
- 긴 아기 이름은 홈·선택 시트·설정에서 별도로 점검했다. 사진 업로드는 격리 브라우저의 테스트 아기와 앱 아이콘 PNG만 사용했다.
- 기존 백과/FAQ 브라우저 시나리오 18개 통과. 월령 13개·FAQ 89개 접근, 조건/금기/긴급 안내, 읽기 상태, 검색·오프라인 경로 보존을 확인했다.
- TypeScript·전체 소스 ESLint·webpack 배포 빌드(23개 페이지) 통과. 기존 middleware 파일명 안내는 남아 있다.
- 실제 3219 앱의 홈 카드와 네 탭 헤더 크기를 재확인했다. 공개 GET 3회, 런타임 오류·데이터 변경 API 요청 0개. [실제 앱 결과](main-app-smoke.json)
- 육아·의료 데이터 파일의 해시 일치를 확인했다. 콘텐츠·DB·공유/백업 로직의 변경은 없다.
