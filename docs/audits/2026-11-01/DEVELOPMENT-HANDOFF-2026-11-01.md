# INFANTPEDIA 개발 정리 및 다음 작업

작성일: 2026-11-01 (Asia/Seoul)

## 현재 상태

기존 UI 디자인을 유지하며 저장·공유 안정화(STEP 6)를 진행 중이다. 로컬 기록 관리는 계속 가능하다. 클라우드 공유·자동 백업·초대 생성·가져오기는 DB 임시 차단 및 앱 중지 안내 상태다. 새 원자적 백업 SQL과 클라이언트는 준비했지만 운영 적용·앱 전체 연결은 아직 하지 않았다. 커밋·푸시·배포도 하지 않았다.

## 오늘 완료한 작업

### 콘텐츠와 설정

- 꿀팁의 월령·요일·펼침·읽기 위치 유지 및 같은 월령 백과 연결을 개선했다.
- 건강 FAQ에 항목별 출처·검수 상태 표시를 구현했다. 실제 원문 등록과 의료 내용 검수가 완료된 것은 아니다.
- 설정을 계정·아기·가족·앱 환경·데이터 탭으로 나누고 선택한 내용만 표시하도록 했다. 탭 디자인, 선택 시 화면 상단 유지, 주소·뒤로 가기·입력 유지도 다듬었다.
- 계정·아기·공유 대상별 백업 상태와 재시도를 구현하고, 가져오기 실패·불완전 응답·기록 변경 시 기존 기록이 교체되지 않도록 검증을 추가했다. 현재는 중지 상태 안내가 우선 표시된다.

### DB 연결·권한·테스트 데이터

- 기존 Supabase 주소의 DNS·인증 헬스·공개 콘텐츠 연결을 재확인했다.
- 기존 공유 정책에서 공개 프로필 조회·기기 자가 등록으로 접근 범위가 넓어질 수 있는 구조를 확인하고 가상 데이터로 재현했다. 실제 유출 여부는 확인하지 않았다.
- 사용자가 승인한 임시 차단 SQL을 직접 실행했다. 이후 익명 역할의 공유 테이블 5개 접근 거부와 공개 콘텐츠 조회 유지를 확인했다. 서버 역할의 공유 테이블 및 인증 관리자 읽기도 정상 확인했다.
- 본인 테스트 데이터라는 확인 후 소유권을 집계했다. 이후 사용자가 일괄 삭제를 요청해 한 계정으로의 이관안 작성은 취소했다.
- 복구용 로컬 백업을 저장한 뒤 서버 아기 25개와 연결 기기 26개를 삭제했다. 공유 테이블 5개는 모두 0건이며 로그인 계정 4개는 유지된다. 브라우저 로컬 기록은 삭제하지 않았다.

### 새 저장 방식과 이전 연결 정리

- 별도 membership·버전 관리·원자적 스냅샷 읽기/쓰기 SQL 및 클라이언트 모듈을 준비했다. 실패 롤백·오래된 버전 충돌·중복 요청 처리를 로컬 검증했다. 007 SQL은 운영 미적용이다.
- 가족 공유 화면을 기기 보관·일시 중지 안내로 바꾸고, 현재 아기의 이전 연결 정보만 해제하는 확인창을 추가했다.
- 아기·사진·메모·성장·접종 기록과 다른 아기의 연결을 보존한다. 대상이 바뀐 확인창, 취소된 백업, 늦게 도착한 응답도 안전하게 처리한다.
- 자동 전송 및 share/join/push/pull 진입점에서 레거시 요청을 중단한다. 조회 실패를 서버 삭제로 단정하거나 자동으로 연결을 지우지 않는다.

## 확인한 검증과 남은 한계

- 원자적 백업 기반: 로컬 DB 22개, 클라이언트 10개 통과.
- 임시 차단안: 가상 DB 검사 10개 통과.
- 최신 연결 정리: 중지 정책 10개, 백업 16개, 가져오기 17개 통과. 기존 서비스의 세부 검사는 테스트에서만 중지 정책을 우회한다.
- 격리된 가상 프로필 브라우저에서 취소·기록 보존 해제·새로고침 유지·재시도 숨김·360px 다크 모드·온보딩 비활성 등 화면 동작 확인. 공유 테이블 요청 0건, pageerror 0건.
- ESLint, TypeScript, webpack 프로덕션 빌드 통과. 기본 Turbopack 폰트 문제·실제 JWT 권한·다중 DB 세션 동시 저장·새 기기 복원은 별도 검증이 남아 있다.

## 다음 작업 순서

1. **새 아기 등록의 서버 경로 구현**: 로그인 계정을 owner로 지정하고 아기·소유권·최초 스냅샷을 함께 저장한다. 중간 실패 시 일부만 남지 않아야 한다. 이미 삭제한 25개를 다시 이관하지 않는다.
2. **새 저장 방식으로 전체 전환**: 생성·초대·조회·자동 백업·가져오기·복원·관리자 경로를 함께 전환한다. 기존 delete→insert 경로를 폐기하고, 기기 기록을 수락/재연결하는 UX를 구현한다.
3. **실제 계정·기기 검증**: 로그인 역할 차단/허용, 계정 변경·세션 만료, 실패·타임아웃·재시도, 다중 세션 충돌, 새 기기 복원을 확인한다. 검증 후 필요한 최소 접근만 연다.
4. **가족 공유·삭제 완성**: 초대 참여, 권한 변경·철회·해제, 병합, 아기 삭제·계정 탈퇴 시 서버와 기기의 처리 범위를 검증한다.
5. **콘텐츠 검수**: '개월별 하루시간표 점검', '건강FAQ의 검수대기 검증', 실제 출처 등록·답변 대조, 발열 기준·위험 문구 검토를 진행한다. 연결 복구 후 온라인 팁/검색 QA도 남아 있다.
6. **공개 전 QA**: Turbopack 오류, 실기기·글자 확대·스크린리더·키보드·다크 모드, PWA 설치·오프라인·업데이트·개인 데이터 캐시, 부모 사용성 관찰을 진행한다.
