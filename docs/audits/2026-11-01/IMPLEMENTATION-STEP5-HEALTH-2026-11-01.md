# STEP 5 2차 — 건강 FAQ 출처·검수 상태 표시

날짜: 2026-11-01 (Asia/Seoul)

## 할 일 목록

저장소 루트 `TODO.md`를 만들고 사용자가 요청한 **개월별 하루시간표 점검**을 미완료로 등록했다. 0~12개월 시간표의 시간대·순서·기간·합계·월령별 차이와 근거/전문가 검수 점검을 후속 작업으로 남겼다. 이번에는 시간표 데이터 자체를 점검하거나 변경하지 않았다.

## 구현

- 건강 FAQ 항목에 선택적 근거 자료·검수 이력 데이터 모델 추가. 검수 완료 상태는 검수자와 검수일을 함께 요구한다.
- FAQ 상단에 현재 개별 출처·전문가 검수 확인이 진행 전임을 안내한다.
- 접힌 질문에도 검수 대기를 표시한다. 펼친 답변에는 기존 적용 월령과 함께 근거 출처, 의료 검수 상태, 검수일을 표시한다.
- 출처가 없는 경우 ‘근거 원문 미등록’, 검수 이력이 없으면 ‘전문가 검수 대기·검수일 미등록’으로 표시한다. 확인되지 않은 기관·문서를 개별 답변의 근거로 연결하지 않았다.
- 이후 등록되는 HTTPS 출처는 새 창 링크로 제공한다. 이번에는 실제 출처 링크를 등록하지 않았다.

## 검증

- 변경 파일 ESLint 오류/경고 0.
- `npm run build -- --webpack`: TypeScript 포함 최종 빌드 통과.
- 기준 Git 데이터와 비교해 질문·답변·긴급도·적용 월령·태그가 변경되지 않았음을 확인.
- 2개월 건강 FAQ에서 ‘기저귀’ 검색 후 답변을 열고 출처·검수 정보가 표시되는지 확인.
- 390px/360px에서 출처·검수 정보 표시와 360px 문서 가로 넘침 없음 확인.
- 검증은 기존 가상 프로필의 로컬 QA 환경에서 수행. 의료 정보의 정확성이나 실제 운영 권한을 검증한 결과가 아니다.
