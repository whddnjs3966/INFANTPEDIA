# STEP 5 1차 — 생활 자료 선택 상태 유지와 백과 연결

날짜: 2026-11-01 (Asia/Seoul)

## 반영 내용

- 꿀팁 월령을 URL `month`로 관리한다. 하단 꿀팁 탭의 기본 주소로 돌아오면 현재 아기의 마지막 선택 월령을 복원한다.
- 기존 읽기 세션 저장소를 재사용해 아기·월령별 시간표 펼침, 시간표 항목 설명, 식단 펼침·요일, 주제별 팁 펼침, 일반 팁 선택을 분리한다.
- 일반 팁은 첫 표시부터 기억하고 ‘다른 팁 보기’를 누를 때만 교체한다.
- 읽던 위치를 복원한다. 동적 컴포넌트와 원격 목록의 로딩 표시를 사용하며, 저장소가 차단되면 기존 읽기 저장소의 메모리 방식으로 동작한다.
- 시간표에 같은 월령의 수면·수유·놀이 가이드 링크, 식단에 이유식·식재료 가이드 링크를 추가했다. 개별 식재료 상세 검색을 새로 구현한 것은 아니다.
- 월령을 바꿀 때 이전 월령의 원격 팁이 잠깐 표시되지 않도록 응답을 요청 월령·재시도 키와 연결했다. 이전 요청은 중단한다.
- 하단 꿀팁 링크의 기본 스크롤 초기화가 읽기 위치 복원과 충돌하지 않도록 조정했다.

저장은 현재 브라우저 세션의 읽기 편의 기능이며 정식 기록이나 클라우드 백업이 아니다. 의료 수치·답변·식단 내용은 변경하지 않았다.

원격 주제별 팁은 기존 Supabase 연결 문제로 실패 안내가 표시됐다. 해당 온라인 목록의 펼침 복귀는 구현했지만 실제 서버 응답을 사용한 브라우저 검증은 남아 있다. 기본 Turbopack 폰트 문제는 이번에 재검증하거나 수정하지 않았으며 Webpack 빌드를 사용했다. 실기기·스크린리더 검증도 별도다.
