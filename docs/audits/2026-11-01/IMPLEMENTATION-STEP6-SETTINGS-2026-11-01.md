# STEP 6 1차 — 설정 구조와 기록 보관 안내

날짜: 2026-11-01 (Asia/Seoul)

## 요청한 TODO

루트 `TODO.md`에 **건강FAQ의 검수대기 검증**을 미완료로 추가했다. 기존 **개월별 하루시간표 점검**도 미완료로 유지했다. 실제 FAQ 원문 대조와 의료 검수는 이번 작업에서 진행하지 않았다.

## 반영 내용

- 설정을 내 계정 / 아기 관리 / 가족과 공유 / 앱 환경 / 데이터 관리의 다섯 영역으로 나누고 상단 바로가기를 추가했다.
- 아기 추가를 환경 설정에서 아기 관리로 옮겼다. 테마·버전·개인정보 안내는 앱 환경에 모았다.
- 영역 제목은 h2, 내부 항목 제목은 h3로 구성했다. 공통 SectionHeader는 선택적인 제목 수준을 지원하며 기존 화면 기본값 h2는 유지한다.
- 데이터 관리에 현재 아기의 성장·접종 기록 수와 로그인/공유 연결 여부를 표시했다. 기존 아기별 조회 규칙을 재사용한다.
- 로그인·공유 연결을 백업 완료와 구분했다. 현재 저장소의 전역 lastSyncAt만으로 특정 아기의 백업 완료를 표시하지 않는다.
- 프로필 삭제, 이 브라우저 전체 초기화, 서버 기록 파기의 범위를 안내에서 구분했다. 기존 삭제 처리 로직이나 서버 파기 절차를 새로 구현한 것은 아니다.

## 검증

- 변경 파일 ESLint 오류/경고 0.
- 최종 `npm run build -- --webpack`: TypeScript 포함 빌드 통과.

- 아기 추가 폼 열기·취소 확인. 새 프로필이나 기록을 저장하지 않았다.
- 데이터 관리 바로가기와 기록 보관 카드→가족 공유 설정 연결 확인.
- 360px 설정 상단·다섯 영역·바로가기 표시, 가로 넘침 없음. 390px 기록 보관 카드 확인.
- 삭제·초기화·탈퇴·공유 연결은 실행하지 않았다. 운영 DB 권한, 로그인 사용자 백업, 서버 데이터 파기는 검증하지 않았다.
